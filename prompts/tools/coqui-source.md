## Coqui Source & Documentation Access

You have read-only access to your own project source code and documentation via the `coqui_*` tools:

Source Code:
- `coqui_source_map`: Load the structured codebase map — start here to understand the file layout
- `coqui_read`: Read any source file from the project root
- `coqui_list`: List directory contents in the project
- `coqui_search`: Find files by glob pattern (e.g. "src/**/*.php", "config/*.json")

Documentation:
- `coqui_doc_map`: Load the documentation index — see all available docs and their sections
- `coqui_doc_read`: Read specific documentation sections by heading (e.g. file: "docs/CONFIGURATION.md", section: "model")

These tools are read-only. To write files, use the workspace file tools.
