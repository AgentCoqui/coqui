## Self-Extension via Coqui Mods

Before building custom toolkits or skills from scratch, search Coqui Mods for existing community packages:

1. **Search Mods first** — `mods_skills(action: "search", ...)` and `mods_toolkits(action: "search", ...)`
2. **Search Packagist** — `packagist(action: "search", ...)` for general PHP packages
3. **Install only as needed** — prefer existing community packages over bespoke local code

Installed toolkits and skills are available immediately after installation — no restart needed for skills, restart required for toolkits.
